## Overview

**BizIntel AI** is an AI-powered business intelligence platform that uses multiple AI agents to analyze business performance, generate actionable insights, and produce professional PDF reports.

The platform combines financial data analysis with AI-driven reasoning to support better business decisions.

## Key Features

- **Multi-Agent Analysis:** Specialized AI agents collaborate to analyze business performance.
- **Financial Insights:** Evaluates sales, expenses, profit, and profit margins.
- **AI-Powered Recommendations:** Generates business improvement suggestions.
- **Interactive Dashboard:** Presents important business metrics.
- **PDF Report Generation:** Creates downloadable business intelligence reports.

## Technology Stack

## Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/BizIntel-AI.git
cd BizIntel-AI
```

**2. Create a virtual environment**

```bash
python -m venv .venv
```

**3. Activate the environment**

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Configure environment variables**

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=openai/gpt-oss-20b
```

**6. Run the backend**

```bash
py app.py
```

**7. Run the frontend**

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

## Security

- API credentials are stored in environment variables.
- `.env` files should never be committed to GitHub.
- Sensitive credentials must remain private.
